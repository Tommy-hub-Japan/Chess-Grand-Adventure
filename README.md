# 👑 グランド・チェス・オデッセイ 〜賢佑と伝説のチェス海賊団〜

ポケモンやワンピース海賊無双のワクワクする冒険・無双演出を取り入れた、賢佑くん専用の3DキャラクターRPGチェスゲームです。
パソコンはもちろん、iPadやAndroidなどの**別のタブレットからでもURLを開くだけでいつでも遊べる**ように、GitHub Pagesでの公開に完全対応しています。

---

## 🚀 別のタブレットで遊べるようにする手順（GitHub Pagesでの無料公開方法）

このフォルダ内のファイルをそのままGitHubにアップロードするだけで、専用のWebゲームURLが発行されます。

### 手順1：GitHubで新しいリポジトリを作る
1. [GitHub](https://github.com/) にログインし、右上の **「＋」** ➔ **「New repository」** をクリックします。
2. **Repository name** に好きな名前（例：`kensuke-chess-rpg`）を入力します。
3. **Public**（公開）を選択し、下の **「Create repository」** をクリックします。

### 手順2：ファイルをアップロードする
1. 作成されたページの **「uploading an existing file」** という青いリンクをクリックします。
2. このフォルダ（`02_Chess Game`）の中にある以下のファイル・フォルダをすべてドラッグ＆ドロップします：
   - `index.html`
   - `css` フォルダ（中の `style.css`）
   - `js` フォルダ（中の `sprites.js`, `audio.js`, `data.js`, `chess.js`, `game.js`）
   - `.nojekyll`
   - `README.md`
3. 下の **「Commit changes」** という緑色のボタンを押してアップロード完了です。

### 手順3：GitHub Pagesを有効にしてタブレットで開く
1. リポジトリ画面の上部メニューにある **「Settings（設定）」** ➔ 左メニューの **「Pages」** を開きます。
2. **Branch** の項目で `None` を **`main`（または `master`）** に変更し、**「Save」** を押します。
3. 1〜2分ほど待つと、`https://<あなたのGitHub名>.github.io/kensuke-chess-rpg/` のようなURLが表示されます。
4. そのURLを**タブレットのブラウザ（SafariやChrome）で開いてホーム画面に追加**すれば、いつでもゲームアプリのように遊べます！

## ✨ 主な機能とアップデート内容

1. **アニメーション・オープニング＆タイトル画面**
   - 起動すると、3Dチェス駒やキャプテン・ケンスケ、相棒のタコ・ワシたちが躍動するタイトル画面が表示されます。
   - **「最初から冒険をはじめる」**（第1章からスタート）と**「続きから冒険する」**（セーブした章や対局途中の盤面から再開）を選択できます。
2. **物語やバトルの途中でいつでもセーブ可能**
   - 1手ごとの自動セーブに加え、画面上部の **「💾 セーブ」** ボタンやバトル画面左の **「💾 この盤面で途中セーブする」** ボタンから、いつでも好きなタイミングでセーブできます。
3. **第1章開始時のプロローグ物語アニメーション**
   - 「最初から」を選ぶと、最終ゴールである伝説の秘宝『チェックメイト・クラウン』や冒険の目的がアニメーション付きストーリーで語られ、没入感を高めます。
4. **章クリアによる段階的ストーリー解放**
   - 最初から第2章〜第6章は表示されず、まずは「第1章」の課題に集中できます。前章のボスをチェックメイトで突破して初めて、次の章（次の目的・課題）と新しい仲間が解放されます。
5. **各ステージ開始時の「VSバトル突入アニメーション」**
   - ステージを選ぶと、いきなり盤面には移らず、まずキャプテン・ケンスケと敵ボスが対峙する迫力のVSアニメーション画面と敵ボスの挑戦セリフが表示され、そこからチェス盤面へと突入します。
6. **常時動く3Dキャラクターチェス駒＆立体アニメーションキャラ**
   - ナイトは「羽ばたくペガサス馬」、ルークは「重装甲キャッスル・ゴーレム」、ビショップは「魔法クリスタル杖の僧侶」、クイーンは「光のティアラ女帝」、キングは「黄金冠のキャプテン王」、ポーンは「剣と盾の見習い海賊兵」として3Dシェーディング造形され、盤面上で常時イキイキと動きます。
7. **壮大なクラシック管弦楽（オーケストラ）調BGM＆ポップなアニメ風ボイス**
   - ストリングス（弦楽合奏）・ホルン・チェロ・ハープを重ねた壮大なRPGクラシック交響曲BGMと、明るく元気なポップ調のボイス読み上げを搭載しています。
